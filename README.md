> **线上访问**：https://hazhanglei.github.io/wire-process-calc/  
> **版本**：工程表单导出版 V16  
> **最后更新**：2026-09-09

---

## 一、工具说明

本工具用于 **USB / 数据线材**的工艺参数核算，支持：

- **多规格芯线混绞 / 并排**（如 2×28AWG + 2×36AWG + 1×Kevlar 复合结构）
- **圆形线（圆整绞合）** 和 **扁平线（跑道型并排）** 两种外观形态
- 自动计算：导体外径、成型外径、推荐绞距、单根铜丝/绝缘/外被用量（kg/m）、成品总尺寸
- **一键导出工程表单（.xls）**，可直接用于生产工单 / 品质检验记录

### 适用场景

| 场景 | 说明 |
|------|------|
| 新线材 NPI 开发 | 输入铜丝规格 → 快速核算整束外径及胶料用量 |
| 工艺变更评估 | 修改绞距倍数 / 包胶厚度 → 对比尺寸与用量变化 |
| 工程表单填写 | 直接导出 .xls，作为生产工单和 IQC 检验依据 |
| 多规格混绞设计 | 支持多组不同芯线规格并行输入，自动均方根计算成缆基准 |

## 二、计算公式详解

### 2.1 常量与默认值

```
铜密度 RHO_CU      = 8.89  g/cm³
绞入损耗 K_LAY_CU  = 1.02  （102%）
成缆系数 CABLING_FACTOR（按芯数索引）：
  1芯=1.0  2芯=2.0  3芯=2.154  4芯=2.414  5芯=2.7
  6芯=3.0  7芯=3.0  8芯=3.3    9芯=3.6    10芯=4.0
  >10芯  = 1.15 × √N
默认胶料密度：
  PVC = 1.35   TPE = 1.10   TPEE = 1.20   TPU = 1.20
```

---

### 2.2 芯线（单根）计算

> 以下公式对每组芯线规格分别计算，变量说明见表。

#### 铜丝截面积

```
areaCu = N × (π / 4) × d²
其中：
  N  = 铜丝股数
  d  = 单根铜丝直径 (mm)
```

#### 补强丝（Denier 单位换算）

```
areaYarn = D / (9000 × 1.44) × 0.1   （mm²）
其中：
  D = Denier 值（如 1000D）
  1.44 = 尼龙/芳纶补强丝密度 g/cm³
  若 D = 0，则 areaYarn = 0
```

#### 导体外径（含铜丝+补强丝）

```
condOD = 1.155 × √( 4 × (areaCu + areaYarn) / π )
其中 1.155 = 束绞间隙补偿系数
```

#### 芯线成型外径（导体 + 绝缘）

```
coreOD = condOD + 2 × insThick
其中 insThick = 绝缘厚度 (mm)
```

#### 推荐芯线绞距

```
layCond = condOD × layMult
其中 layMult = 绞距倍数（默认 8）
```

#### 单根铜丝用量

```
W_cu (kg/m) = areaCu × 8.89 × 1.02 / 1000
```

#### 单根绝缘用量

```
W_ins (kg/m) = [ (π/4)×coreOD²  −  (π/4)×condOD² ] × ρ_ins / 1000
其中 ρ_ins = 绝缘材质密度（从下拉框取值）
```

---

### 2.3 圆形线（圆整绞合）

> 所有芯线汇总后，按均方根法计算成缆基准尺寸。

#### 等效芯线外径（均方根法）

```
d_eff = √( Σ(coreOD² × qty) / 总芯数N )
```

#### 成缆外径

```
cabOD = d_eff × K
其中 K = CABLING_FACTOR[N]（≤10芯） 或 1.15×√N（>10芯）
```

#### 成品外径

```
finalOD = cabOD + 2 × jackThick
其中 jackThick = 外被包胶厚度 (mm)
```

#### 成缆绞距

```
layCable = cabOD × cabLayMult
其中 cabLayMult = 成缆绞距倍数（默认 40）
```

#### 外被用量

```
W_jacket (kg/m) = (π/4) × (finalOD² − cabOD²) × ρ_jack / 1000
```

#### 总铜丝用量

```
W_total_cu = Σ( W_cu × qty )
```

---

### 2.4 扁平线（跑道型并排）

> 扁平线无成缆绞距（平行不绞），改为输入芯线间距。

#### 内部排线尺寸

```
W_in = Σ(coreOD × qty) + (总芯数 − 1) × spacing
T_in = max(coreOD)
其中 spacing = 芯线间距 (mm)
```

#### 成品尺寸

```
W_out = W_in + 2 × jackThick
T_out = T_in + 2 × jackThick
```

#### 外被用量

```
S_out  = (W_out − T_out) × T_out  +  (π/4) × T_out²
W_jacket = (S_out − Σ(coreArea × qty)) × ρ_jack / 1000
其中 coreArea = (π/4) × coreOD²
```

#### 成缆绞距

```
layCable = "平行不绞"
```

## 三、使用方法

### 3.1 界面说明

页面从上到下共 4 个功能区块：

```
┌─────────────────────────────────────────────┐
│ ① 输入芯线工艺参数（多规格混绞/并排）          │
│   - 每规格 7 个输入框：                       │
│     单根铜直径 / 铜丝股数 / 补强丝 /          │
│     绞距倍数 / 绝缘厚度 / 绝缘材质 / 芯线数量  │
│   - 点「+ 添加芯线规格」增加多组               │
├─────────────────────────────────────────────┤
│ ② 成品外观与包胶参数                          │
│   - 线材形状（圆形 / 扁平）                    │
│   - 外被包胶厚度、外被材质、外被填充、         │
│     成缆绞距倍数（圆线）/ 芯线间距（扁线）     │
├─────────────────────────────────────────────┤
│ ③ 操作按钮                                   │
│   ⚡ 计算更新    📥 导出工程表单              │
│   ⚙️ 胶料设置   🔄 清空数据                  │
├─────────────────────────────────────────────┤
│ ④ 计算结果（本地查阅）                        │
│   - 芯线各项明细表                            │
│   - 成品外观与外被汇总表                       │
└─────────────────────────────────────────────┘
```

### 3.2 操作步骤

1. **填写芯线规格**
   - 单根铜直径、铜丝股数（必填）
   - 补强丝（Denier，无则填 0）
   - 绝缘厚度、绝缘材质（下拉选择）
   - 芯线数量（每组有几根）

2. **设置成品外观**
   - 圆形线：填入外被包胶厚度、成缆绞距倍数（默认 40）
   - 扁平线：填入外被包胶厚度、芯线间距（默认 0 即紧贴）

3. **点击「⚡ 计算更新」**
   - 结果即时显示在下方两张表格

4. **导出工程表单**
   - 点击「📥 导出工程表单(Excel)」→ 自动下载 .xls 文件
   - 文件名：`项目线材工艺明细表_YYYYMMDD.xls`
   - 包含：项目号、尺寸、外被/中被/芯线各字段，可直接用于工单

5. **自定义胶料**
   - 点击「⚙️ 胶料材质设置」→ 新增/修改材质密度
   - 保存在浏览器 localStorage，下拉框自动刷新

### 3.3 导出文件字段说明

| 列名 | 数据来源 | 说明 |
|------|----------|------|
| 长径 | `finalL` | 圆线 = 成品外径；扁线 = W_out |
| 短径 | `finalS` | 圆线 = 空；扁线 = T_out |
| 外被材质 | 下拉框 | 纯文字（如 TPU） |
| 外被填充 | 外被填充输入框 | 如 `1000D Kailev` |
| 芯线铜材质 | 固定 | 铜（T2） |
| 芯线规格 | `cu_d` | 单根铜丝直径 |
| 支数 | `cu_n` | 铜丝股数 |
| 填充 | `filler` | 补强丝 Denier 值 |
| 绝缘 | 下拉框 | 绝缘材质纯文字 |
| 绞距 | `layCond` | 推荐芯线绞距 (mm) |
| ID | `coreOD` | 芯线成型外径 (mm) |

## 六、常见问题

**Q：导出的 .xls 用 WPS / Excel 打开有格式警告？**  
A：正常。工具生成的是带 Excel 命名空间的 HTML 表格文件，扩展名为 .xls，主流软件均可正常打开。

**Q：自定义胶料保存后换浏览器失效？**  
A：`localStorage` 绑定浏览器域名。换浏览器需重新设置，或点「⚙️ 胶料材质设置」查看当前默认值。

**Q：扁平线为什么没有成缆绞距？**  
A：扁平线（跑道型并排）各芯线平行铺设不绞合，绞距无意义，故显示"平行不绞"。

**Q：支持多少芯线？**  
A：不限。CABLING_FACTOR 数组仅覆盖 10 芯以内，超出部分用公式 `1.15 × √N` 计算。
